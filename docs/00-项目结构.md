# 项目结构

> 最后一次更新：1.2.5
> 用途：换人/换会话接手时先看这里，再按需读具体文件。

## 顶层

| 目录 | 作用 |
| --- | --- |
| `android/` | Android 宿主 App（Kotlin + Compose） |
| `cli/` | 打包 CLI + 电脑端服务（Node，零依赖） |
| `sdk/` | `pocket-sdk.js` 源码（会被打进 APK 的 assets，运行时注入页面） |
| `docs/` | 文档 |
| `examples/` | 示例应用（`01-hello` `02-motion` `03-tool`） |
| `tools/` | 桌面快捷方式调用的启动 / 关闭脚本 |
| `dist/` | 产物：`pocket-host.apk`、`pocket-host.json`、`*.pkt`（不入库） |

## Android 端（`android/app/src/main/java/io/pocket/host/`）

| 文件 | 职责 |
| --- | --- |
| `PocketApp.kt` | Application：初始化仓库、安装器、内置应用 |
| `MainActivity.kt` | 首页/文件夹/设置路由，各种弹窗状态机 |
| `core/PackageRepository.kt` | 已安装应用列表（apps.json）、文件夹、extraHosts 记忆 |
| `core/PackageInstaller.kt` | 安装/更新 `.pkt`：只替换 `www`，保留 `data`；同名复用 id；`bumpVersion()` |
| `core/AppManifest.kt` | manifest 解析（id/name/version/entry/permissions/network/folder…） |
| `core/InstalledApp.kt` | 已安装应用的持久化结构 |
| `core/LanClient.kt` | 局域网发现（UDP 8571）+ 拉取应用列表 / 下载 pkt / 图标 |
| `core/PocketStorage.kt` | `pocket.storage` 的落地（`files/apps/<id>/data/storage.json`） |
| `core/SafeZip.kt` | zip 解包防穿越、体积限制 |
| `runner/AppRunnerActivity.kt` | 应用容器：WebView、返回键、全屏/状态栏、清理数据 |
| `runner/PocketWebViewClient.kt` | 虚拟 https 源 `https://<appId>.pocket.local/...`，注入 SDK、`no-store` |
| `core/AiConfig.kt` | AI 对话配置与调用（DeepSeek / OpenAI 兼容中转站） |
| `core/ImageConfig.kt` | 生图配置与调用：无参考图走 `/images/generations`，有参考图走 `/images/edits`（multipart） |
| `core/TransferStore.kt` | 互传文件仓库：`files/transfer` + `index.json`，收件/发件分目录 |
| `core/TransferServer.kt` | 手机端 HTTP 服务（8572）：offer/upload/files/Range/CORS |
| `core/TransferDiscovery.kt` | UDP 8571 设备发现：响应探测、广播自己、维护设备表 |
| `core/TransferClient.kt` | 向其它设备推文件（offer + PUT 流式上传 + 进度） |
| `core/TransferRuntime.kt` / `TransferEvents.kt` | 互传启动入口 / 页面事件总线 |
| `runner/PocketBridge.kt` | `window.pocket` 的原生实现：存储、网络代理（白名单）、TTS、AI、生图、文件与互传 |
| `runner/RunnerScreen.kt` | 容器的 Compose 外壳（进度条、对话框宿） |
| `ui/HomeScreen.kt` | 首页：应用卡片、文件夹、搜索、AI / 画图入口 |
| `ui/LanImportSheet.kt` | 「从电脑导入」：自动连接、应用列表、安装/更新（**装完留在本页**） |
| `ui/AppDetailSheet.kt` | 应用详情：打开、删除、移到文件夹、清除数据 |
| `ui/SettingsScreen.kt` | 设置：检查更新、AI 模型配置、生图模型配置 |
| `ui/AiChatScreen.kt` / `AiSettingsSheet.kt` | 手机端 AI 提问页 / 模型配置弹层（DeepSeek、中转站） |
| `ui/ImageGenScreen.kt` / `ImageSettingsSheet.kt` | 画图页（提示词、参考图、保存相册、分享）/ 生图配置弹层 |
| `ui/HostUpdateSheet.kt` | 口袋自身从电脑端检查更新并下载安装 |
| `ui/FolderScreen.kt` | 文件夹内的应用列表 |
| `ui/ImportSheet.kt` / `PasteHtmlDialog.kt` | 从文件导入 / 粘贴 HTML 新建 |

## JS SDK（`sdk/src/pocket-sdk.js`）

注入到每个页面，暴露 `window.pocket`：

- `app / ui / storage / http / device / clipboard / share / file / notify / system / tts / ai / image / files / transfer`
- 兼容层：`speechSynthesis`、`fetch`（翻译接口接管）、viewport/安全区
- 与原生交互协议：`PocketNative.call(json)` / `callAsync(json)` + `__pocketResolve` / `__pocketEvent`

## CLI / 电脑端（`cli/`）

| 文件 | 职责 |
| --- | --- |
| `bin/pocket.js` | 命令入口：`init` / `pack` / `serve` |
| `lib/pack.js` | 打包 `.pkt`（manifest 规范化、64MB 上限） |
| `lib/serve.js` | 电脑端：管理页、`/api/apps`、`/api/host`、`/api/upload`（HTML 自动包）、`/api/shutdown`、PID 文件、UDP 8571 发现 |
| `lib/pkt-reader.js` | 读取 pkt 里的 manifest/图标 |
| `lib/zip.js` | 极简 zip 读写 |

## 运行时数据（手机上）

```
/data/data/io.pocket.host/files/
├── apps.json                       已安装应用索引（含 id/version/whitelist/folder/extraHosts）
├── transfer/                       互传文件（独立于系统文件）
│   ├── index.json                  传输记录（id/名称/大小/方向/来源/时间）
│   ├── inbox/yyyy-MM-dd/           收到的
│   └── sent/yyyy-MM-dd/            发出的
└── apps/<id>/
    ├── manifest.json
    ├── www/                        功能文件（更新时整体替换）
    └── data/storage.json           应用数据（更新时保留）
```

## 内置应用（`builtin-apps/` → `assets/builtin/*.pkt`）

源码在仓库根目录 `builtin-apps/<名字>/`，用 `node cli/bin/pocket.js pack builtin-apps/<名字> -o android/app/src/main/assets/builtin/<名字>.pkt` 打包。
目前有：`hello`、`motion`、`tool`、`transfer`（互传）、`files`（口袋文件）。升级后会按 id 补装缺失的内置应用。

## 电脑端数据

```
dist/
├── pocket-host.apk / pocket-host.json   口袋自身安装包与版本信息
├── *.pkt                                给手机的应用
└── .pocket-server.json                  运行中的 PID/端口（关闭脚本用）
library/                                 本机 HTML 收藏（拖进来的原始 HTML）
└── transfer/                            手机发给电脑的文件（互传专用，与收藏分开）
```
