# 交付指南：把项目做成能拖进口袋的文件

这份文档给**其他工程 / AI 助手**看：你的项目最终要产出什么文件、怎么放到电脑端服务里、手机上要注意什么。
不需要了解口袋内部怎么实现。

---

## 1. 最终产物是什么

口袋里的每个「小应用」就是一个 `.pkt` 文件，本质是 zip：

```
xxx.pkt
├── manifest.json     应用信息（名字、版本、入口、权限）
├── index.html        入口页面
└── ...               其余静态资源（图片、字体、js、css 都可以放）
```

PC 端管理页同时接受 **`.html`** 和 **`.pkt`** 两种拖入方式。

---

## 2. 最省事：单文件 HTML 直接拖进去

如果你的项目是**一个自包含的 HTML**（样式、脚本都写在这一个文件里，图片用 base64 或外链），那就什么都不用做：

1. 电脑上双击「口袋电脑端」，打开管理页 `http://<电脑IP>:8570/`
2. 把 `我的小玩意.html` 直接拖进页面

服务端会自动包成 `.pkt`：

| 规则 | 说明 |
| --- | --- |
| 应用名 | 取**文件名**（`肖1000刷题.html` → 应用「肖1000刷题」） |
| 首次拖入 | 新建应用，id 为 `local.<名字>-<内容hash>` |
| 再次拖入**同名**文件 | 视为更新：沿用原 id、版本号末位 +1、**手机上的存档数据全部保留** |
| 改名再拖 | 会被当成一个新应用（旧应用的存档不会跟过来） |

> 所以更新时**不要改文件名**，直接覆盖拖同一个名字即可。

---

## 3. 需要多文件 / 要自定义信息：打 .pkt

有图片、字体、多个 js/css 文件，或者想自己定 id、图标色、网络白名单时，建一个目录：

```
my-app/
├── manifest.json
├── index.html
└── assets/...
```

`manifest.json` 最小示例：

```json
{
  "schema": "pocket.app/1",
  "id": "local.my-app",
  "name": "我的小玩意",
  "version": "1.0.0",
  "entry": "index.html",
  "description": "一句话介绍",
  "accent": "#7C5CFF",
  "permissions": ["storage", "http", "haptic", "clipboard", "share", "external"],
  "network": { "whitelist": ["api.example.com"] }
}
```

字段说明：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 小写字母/数字/点/下划线/连字符；**更新必须用同一个 id** |
| `name` | 是 | 手机桌面显示的名字 |
| `version` | 是 | 字符串；更新时调大（`1.0.1` → `1.0.2`） |
| `entry` | 是 | 入口文件，通常是 `index.html` |
| `accent` | 否 | 图标底色 `#RRGGBB` |
| `permissions` | 否 | 能力白名单，不写等于全部拒绝 |
| `network.whitelist` | 否 | 允许 `fetch` / `pocket.http.request` 访问的域名（不含协议和路径） |

打包：

```bash
node cli/bin/pocket.js pack ./my-app -o dist/my-app.pkt
```

然后把生成的 `.pkt` 拖进电脑端管理页（或直接拷到 `dist/` 目录，管理页会自动扫描到）。

也可以不写 manifest，直接：

```bash
node cli/bin/pocket.js pack --html ./index.html -o dist/my-app.pkt --name "我的小玩意" --version 1.0.0
```

## 4. 手机上必须注意的 4 件事

1. **别写死宽度**：不要 `width:1200px`、不要横向滚动。用 `max-width:100%`、`dvh`、`flex/grid` 自适应。
2. **别依赖鼠标**：`hover`、`mousedown` 取词/拖拽在手机上都不触发。需要「点词发音 / 划词翻译」这类交互时，改成**长按 500ms 或双击**，并在 `touchend` 里处理，滑动翻页时不要误触。
3. **数据要可保留**：存档用 `localStorage` 或 `pocket.storage`，不要依赖服务器文件。这样应用更新（换功能文件）时数据不丢。
4. **网络请求**：只允许 `https://`，且域名要写进 `manifest.network.whitelist`；浏览器里被 CORS 拦的接口，在口袋里可以直接用 `pocket.http.request` 走原生网络栈。

需要「读剪贴板 / 存储 / 分享 / 发音 / 弹窗」等能力时，用注入好的 `window.pocket`，不用自己实现（详见 `03-JS-API.md`）。
宿主会自动注入 SDK 和移动端兼容层（viewport、安全区、字体缩放），页面不用手动引入任何脚本。

## 5. 交付自检清单

- [ ] 断网打开也不白屏（没有依赖必须联网才能渲染的资源）
- [ ] 手机上 375px 宽不横向滚动、按钮可点（≥ 40px 高）
- [ ] 存档写在 localStorage / `pocket.storage`，刷新后还在
- [ ] 更新时文件名（拖 HTML）或 `manifest.id`（打 pkt）与上一版一致
- [ ] `manifest.version` 比手机上的版本大
- [ ] 需要联网的域名已写进白名单
- [ ] 单个包 ≤ 64MB

## 6. 常见问题

**Q：拖进去后手机上没看到？**
管理页每 2 秒自动刷新列表；手机端「+ → 从电脑导入」也要点一下刷新/重连。

**Q：更新后手机上的数据丢了？**
检查是不是改了文件名（HTML 直拖）或改了 `manifest.id`（pkt），这两种都会变成新应用。

**Q：页面白屏？**
确认 `entry` 指向的文件存在；外链 CDN 在离线时不可用，建议把关键 js/css 内联进 HTML。

**Q：接口报 `E_NETWORK_DENIED`？**
把域名补进 `network.whitelist` 重新打包；或在手机弹窗里点一次「允许」。
