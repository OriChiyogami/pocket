# 口袋 Pocket · 插件包规范（v1）

> 一个 `.pkt` 文件就是一个可安装的小应用。它本质是 zip 压缩包，包含一份 `manifest.json` 与网页资源。

## 1. 包结构

```
my-app.pkt
├── manifest.json        必需，应用描述
├── index.html           必需（默认入口，可在 manifest.entry 中修改）
├── icon.png             可选，建议 192×192
└── assets/...           任意静态资源（css / js / 图片 / 字体 / 音视频）
```

约束：

| 项目 | 上限 |
|---|---|
| 解压后总体积 | 64 MB |
| 单个文件 | 32 MB |
| 文件数量 | 4000 |
| 路径 | 不允许 `..`、绝对路径、反斜杠逃逸 |

zip 内如果所有文件被包在一个同名文件夹里（例如 `my-app/manifest.json`），宿主会自动识别该层目录为根。

## 2. manifest.json

```json
{
  "schema": "pocket.app/1",
  "id": "com.example.timer",
  "name": "番茄钟",
  "version": "1.0.0",
  "entry": "index.html",
  "icon": "icon.png",
  "description": "一个安静的专注计时器",
  "accent": "#7C5CFF",
  "display": {
    "orientation": "portrait",
    "statusBar": "light",
    "fullscreen": false,
    "background": "#FFF7F6FA"
  },
  "permissions": ["storage", "http", "clipboard", "share", "haptic"],
  "network": {
    "whitelist": ["https://api.example.com"]
  }
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `schema` | string | 否 | 固定 `pocket.app/1`，用于后续版本兼容 |
| `id` | string | **是** | 应用唯一标识。`^[a-z0-9][a-z0-9._-]{0,63}$`，安装后不可更改 |
| `name` | string | **是** | 显示名称，最长 40 字符 |
| `version` | string | 否 | 默认 `1.0.0`，最长 24 字符 |
| `entry` | string | 否 | 入口页面，默认 `index.html`，文件必须存在 |
| `icon` | string | 否 | 相对包根的图标路径；缺省时自动尝试 `icon.png / icon.webp / icon.jpg / icon.svg` |
| `description` | string | 否 | 一句话说明，最长 120 字符 |
| `accent` | string | 否 | 主题色，`#RGB` / `#RRGGBB` / `#AARRGGBB`，用于首页卡片与应用内配色 |
| `display.orientation` | string | 否 | `auto`（默认）/ `portrait` / `landscape` |
| `display.statusBar` | string | 否 | `auto`（默认）/ `light`（深色图标）/ `dark`（浅色图标）/ `hidden`（隐藏） |
| `display.fullscreen` | boolean | 否 | 默认 `false`；`true` 时隐藏系统栏 |
| `display.edgeToEdge` | boolean | 否 | 默认 `false`。为 `true` 时页面延伸到状态栏/导航栏下方，需要用 `--pocket-safe-*` 自行避让 |
| `display.background` | string | 否 | WebView 底色与系统栏底色，避免加载瞬间白闪 |
| `permissions` | string[] | 否 | 能力白名单，见下节。省略即全部拒绝 |
| `network.whitelist` | string[] | 否 | 允许 `pocket.http.request` 访问的域名（不含协议与路径） |

### `id` 与 origin 的关系

宿主为每个应用分配独立域名：

```
id = com.example.timer
origin = https://com.example.timer.pocket.local
```

这样做的好处是 `localStorage`、`IndexedDB`、Cache Storage 按 origin 天然隔离——两个小应用不会互相污染数据。`id` 中的下划线会被替换为连字符以保证域名合法，因此请尽量只用点号与连字符。

## 3. 权限（permissions）

缺省为空，即所有原生能力都不可用。按需声明：

| 权限 | 控制的接口 |
|---|---|
| `storage` | `pocket.storage.*` |
| `http` | `pocket.http.request` |
| `clipboard` | `pocket.clipboard.read / write` |
| `share` | `pocket.share.text` |
| `notify` | `pocket.notify.show` |
| `haptic` | `pocket.ui.haptic` |
| `file` | `pocket.file.pick` |
| `external` | `pocket.system.openExternal`、页面内跳转外部链接 |

未声明的能力被调用时，会抛出一个 `code = "E_PERMISSION"` 的 Promise 拒绝，不会静默失败。

## 4. 网络访问

`pocket.http.request` 走原生网络栈，不受浏览器 CORS 限制，但受两层管控：

1. `manifest.network.whitelist` 中声明过的域名直接放行
2. 未声明的域名首次请求时，会弹出确认框；用户点「允许」后，该域名被记住

页面里直接写的 `<img src>`、`<link href>`、`<script src>` 等子资源不受此限制（会正常走网络），只有顶层页面跳转会交给系统浏览器。

## 5. 打包

```bash
# 目录 → .pkt
node cli/bin/pocket.js pack examples/02-motion -o dist/motion.pkt

# 单文件 HTML → .pkt
node cli/bin/pocket.js pack --html demo.html --name "我的小玩意"

# 生成新项目模板
node cli/bin/pocket.js init ./my-app --name "我的应用" --id local.my-app
```

## 6. 版本与升级

- 同 `id` 再次安装即为覆盖升级，**保留使用统计与本地数据**，仅替换网页资源
- 不同 `id` 视为不同应用
- 删除应用会同时删除其 `www/` 与 `data/` 目录
