# 开发日志

> 长期维护用：记录「为什么这么改」和踩过的坑，避免换会话后重新摸索。
> 格式：日期 · 主题 · 结论/坑。

## 2026-11-05

- **架构定型**：宿主用 WebView 从虚拟 https 域名 `https://<appId>.pocket.local/` 读 `files/apps/<id>/www/`，不依赖 file://，页面可正常用 fetch/CORS 规则。
- **SDK 注入点只有一处**：`PocketWebViewClient.injectIntoHtml()` 在 `<head>` 后插 `<script src="/__pocket/sdk.js">`，保证 SDK 先于页面脚本执行。
- **数据与功能分离**：更新只替换 `www/`，`data/`、localStorage、IndexedDB 全保留；应用 id 不变是前提。
- **电脑端是服务端**：`cli/lib/serve.js` 管理页 + `/api/upload` 收 HTML 自动包成 pkt；同名应用复用 id、版本末位 +1。

## 2026-11-06

- **触屏适配层**（`.build/adapt-html.js` 注入到 `</body>` 前）：
  - 长按 520ms / 双击取词，滑动 12px 取消；长按后系统会选中单词并弹原生菜单，`touchend` 里用系统选区做兜底文本；弹卡片后 `clearSelection()` 清掉选区。
  - 坑：**卡片弹出后会盖住手指按住的单词**，再按坐标取词会取到卡片本身 → 现在取词时先把命中的文本节点记下来（`cardNode/cardOffset`），整句翻译直接用节点，不再依赖坐标。
  - 坑：段落里的 `<b>/<mark>` 会把句子切成多个文本节点，只取当前节点会得到半句（`The cartoon`）→ 片段不成句时回退到块级容器切句，中英混排只取英文片段。
  - 坑：单词的翻译结果迟到，会把整句译文覆盖 → `translateInto` 用 `cardText` 校验，过期结果丢弃。
- **翻译链路**：单词走百度词典 `fanyi.baidu.com/sug`（CORS 不通，走 `pocket.http.request` 原生代理）；整句走 MyMemory。域名写进 manifest 白名单，正规 pkt 安装后不再弹「网络访问请求」。
- **调试手段**：`WebView.setWebContentsDebuggingEnabled(true)` + `adb forward tcp:9222 localabstract:webview_devtools_remote_<pid>` + 自写 CDP 客户端，可直接执行 `Runtime.evaluate` 读页面状态（正式版已移除该开关）。
- **坑：模拟器极慢**，大 HTML 要几十秒才 `readyState=complete`，过早操作会误判「适配层没执行」。判断标准：`window.__pocketTouchAdapter === true` 且 `document.scripts.length >= 3`。
- **广告条式返工**：从电脑导入原来装完就关面板并打开详情（用户体感「弹出去」）→ 改为留在列表、刷新版本、Toast 提示，按钮分 安装/更新/重装。
- **版本识别**：`existingVersion == app.version` 时不应再给「更新」按钮，改为「重装」并视为已是最新。
- **文档分工**：`04-开发与构建指南.md` 只写给其他工程的交付说明（怎么产出能拖进电脑端的文件）；内部构建/发布流程放本日志与 `00-项目结构.md`。

## 发布流程（内部备忘）

```bash
cd android && ../.build/gradle-8.7/bin/gradle assembleRelease
cp app/build/outputs/apk/release/app-release.apk ../dist/pocket-host.apk
# 同步改 android/app/build.gradle.kts 的 versionCode/versionName 与 dist/pocket-host.json
```

签名固定 `android/pocket-release.jks`（不入库）；同包名同签名覆盖安装，Android 保留数据。
