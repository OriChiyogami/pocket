# 开发日志

> 长期维护用：记录「为什么这么改」和踩过的坑，避免换会话后重新摸索。
> 格式：日期 · 主题 · 结论/坑。

## 2026-11-05

- **架构定型**：宿主用 WebView 从虚拟 https 域名 `https://<appId>.pocket.local/` 读 `files/apps/<id>/www/`，不依赖 file://，页面可正常用 fetch/CORS 规则。
- **SDK 注入点只有一处**：`PocketWebViewClient.injectIntoHtml()` 在 `<head>` 后插 `<script src="/__pocket/sdk.js">`，保证 SDK 先于页面脚本执行。
- **数据与功能分离**：更新只替换 `www/`，`data/`、localStorage、IndexedDB 全保留；应用 id 不变是前提。
- **电脑端是服务端**：`cli/lib/serve.js` 管理页 + `/api/upload` 收 HTML 自动包成 pkt；同名应用复用 id、版本末位 +1。

## 2026-11-08

- **手机端生图**：首页「画」→ 提示词 + 最多 4 张参考图 → 结果可存相册 / 分享。
  - 无参考图：`POST {BaseURL}/images/generations`（JSON，`model/prompt/n/size/quality/output_format`）。
  - 有参考图：`POST {BaseURL}/images/edits`（multipart；实测单图/多图都用字段 `image[]` 才稳）。
  - 实测中转站：`generations` 回 `data[].b64_json`；`edits` 回 `data[].url`（oss 直链，可匿名 GET）。所以解析必须同时支持两种，直链还要再下载一次。
  - 读超时给到 300 秒（MCP 里也是这个值），大图 30～90 秒很常见，界面必须有计时 loading。
- **Key 不进仓库**：`android/image-secrets.properties`（`.gitignore` 已排除）→ `app/build.gradle.kts` 读成 `buildConfigField("String","IMAGE_API_KEY",…)` → `ImageConfig` 用 `BuildConfig.IMAGE_API_KEY` 兜底。APK 里带 Key，源码与 GitHub 里没有。
  - 坑：`rootProject.file(...)` 在 `android/` 下，不是仓库根目录。
  - 校验方式：看 `app/build/generated/source/buildConfig/release/io/pocket/host/BuildConfig.java` 里 Key 的字符数（67），不要把内容打印出来。
- **保存到相册**：API 29+ 用 `MediaStore.Images` + `RELATIVE_PATH=Pictures/Pocket` + `IS_PENDING`；API ≤ 28 写公共 Pictures 目录并 `MediaScannerConnection.scanFile`，需要 `WRITE_EXTERNAL_STORAGE`（`maxSdkVersion=28`）运行时权限。
- **参考图回灌测试法**：先用 `/images/generations` 生成一张图，把 `b64_json` 解出来当 `/images/edits` 的参考图，不用另外找素材。

## 2026-11-06（晚）

- **上传入口拆分**：`/api/upload?target=phone|library`——`phone` 只进 `dist/` 打包，`library` 只写 `library/`；页面上两个独立拖拽区（紫=发手机，青=本机收藏）。
- **localStorage 不跟着文件走**：浏览器按来源隔离，`file://` 直接打开时存的数据不会出现在 `http://…/library/xxx` 里。解决办法不是复制数据，而是在打开收藏页时注入一段 `?import=1` 的导入脚本，让用户把旧页面 `copy(JSON.stringify(localStorage))` 的结果粘进来，写进当前来源。管理页每个收藏项都有「迁数据」。
- **AI 思考过程**：`message.reasoning_content` / `reasoning` / `thinking` 以及正文里的 `<thinking>…</thinking>` 统一抽到 `reasoning`，手机聊天页折叠显示；`pocket.ai.chat()` 只返回正文，`chatFull()` 返回 `{text, reasoning}`。
- 坑：改完 `serve.js` 但测试仍是老行为 —— 端口被上一个没关的服务占着，新进程 `EADDRINUSE` 静默退出；先 `POST /api/shutdown` 再起。

## 2026-11-06（下午）

- **长期维护**：仓库推到 GitHub 私有库，个人应用（学习类 HTML、刷题应用）与签名文件一律不入库；`.gitignore` 里固定排除 `dist/*.pkt`、`dist/*.apk`、`examples/kaoyan-english`、`*.jks`、`local.properties`、`.trae`。
- **AI 设计**：Key 存宿主 SharedPreferences，页面只拿 `pocket.ai.chat()`；两种 provider（DeepSeek 固定地址只填 Key / 自定义 OpenAI 兼容填 BaseURL+Key+Model）。不走 `pocket.http.request` 的原因是 AI 调用不应受 manifest 白名单限制，且需要 90s 长读超时。
- **电脑端常驻**：`start-pocket.ps1` 改成 `Start-Process -WindowStyle Hidden` 启动独立 node 进程并立即退出；PID 文件仍由 serve.js 写入，关闭脚本按 PID/端口结束进程。
  - 坑：PowerShell 5.1 的 `Start-Process -ArgumentList` 不会自动给含空格路径加引号，必须自己拼 `"路径"`，否则 node 报 `MODULE_NOT_FOUND`。
- **本机 HTML 收藏**：`library/` 与 `dist/` 同级；上传 HTML 时同时写两份（一份进 dist 打包给手机，一份进 library 方便电脑上随时打开）。接口：`/api/library`、`/api/library/send|delete|rename`、`/library/<file>`。
- **更新按钮语义**：`existingVersion == 远端 version` → 显示「已装」并禁用；只有确实有差异才给「更新」。
- **坑：模拟器偶发 system_server ANR**（"Process system isn't responding"），与口袋无关；`gradle --stop` 释放资源后重启模拟器即可。

## 2026-11-06

- **触屏适配层**（`.build/adapt-html.js` 注入到 `</body>` 前）：
  - 长按 520ms / 双击取词，滑动 12px 取消；长按后系统会选中单词并弹原生菜单，`touchend` 里用系统选区做兜底文本；弹卡片后 `clearSelection()` 清掉选区。
  - 坑：**卡片弹出后会盖住手指按住的单词**，再按坐标取词会取到卡片本身 → 现在取词时先把命中的文本节点记下来（`cardNode/cardOffset`），整句翻译直接用节点，不再依赖坐标。
  - 坑：段落里的 `<b>/<mark>` 会把句子切成多个文本节点，只取当前节点会得到半句（`The cartoon`）→ 片段不成句时回退到块级容器切句，中英混排只取英文片段。
  - 坑：单词的翻译结果迟到，会把整句译文覆盖 → `translateInto` 用 `cardText` 校验，过期结果丢弃。
- **翻译链路**：单词走百度词典 `fanyi.baidu.com/sug`（CORS 不通，走 `pocket.http.request` 原生代理）；整句走 MyMemory。域名写进 manifest 白名单，正规 pkt 安装后不再弹「网络访问请求」。
- **调试手段**：`WebView.setWebContentsDebuggingEnabled(true)` + `adb forward tcp:9222 localabstract:webview_devtools_remote_<pid>` + 自写 CDP 客户端，可直接执行 `Runtime.evaluate` 读页面状态（正式版已移除该开关）。
- **坑：模拟器极慢**，大 HTML 要几十秒才 `readyState=complete`，过早操作会误判「适配层没执行」。判断标准：`window.__pocketTouchAdapter === true` 且 `document.scripts.length >= 3`。
- **广告条式返工**：从电脑导入原来装完就关面板并打开详情（用户体感「弹出去」）→ 改为留在列表、刷新版本、Toast 提示，按钮分 安装/更新/重装。
- **版本识别**：`existingVersion == app.version` 时不应再给「更新」按钮，改为「重装」并视为已是最新。
- **文档分工**：`04-开发与构建指南.md` 只写给其他工程的交付说明（怎么产出能拖进电脑端的文件）；内部构建/发布流程放本日志与 `00-项目结构.md`。

## 发布流程（内部备忘）

```bash
cd android && ../.build/gradle-8.7/bin/gradle assembleRelease
cp app/build/outputs/apk/release/app-release.apk ../dist/pocket-host.apk
# 同步改 android/app/build.gradle.kts 的 versionCode/versionName 与 dist/pocket-host.json
```

签名固定 `android/pocket-release.jks`（不入库）；同包名同签名覆盖安装，Android 保留数据。
