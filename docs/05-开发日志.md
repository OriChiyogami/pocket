## 2026-11-08（电脑端 Electron 重构）

- **电脑端从「网页 + PowerShell 小窗」重构为单一 Electron 桌面应用**（`desktop/`，打包为 `dist/desktop/Pocket-win32-x64/Pocket.exe`）。
  - 悬浮球：100px 深蓝玻璃球，只保留大 P（`desktop/assets/pocket-p.png`），无文字/流光；窗口透明，不再出现方形底色。
  - 主界面：1180×760 全尺寸工作台，左侧玻璃边栏 + 顶部问候/搜索；概览含 4 张指标卡、7/14 天剪贴板活动图、深色「当前连接」卡、最近剪贴板/文件；文件、剪贴板、设备、资源库、设置全部原生页面。
  - UI：深蓝/浅蓝玻璃拟态；液态胶囊导航（切换时拉长回弹）、底部图标 Dock（悬停放大相邻图标）、模块就地放大 + 底部缩略条、水滴分裂筛选、Ctrl+K 命令面板、卡片光斑跟随 + 3D 倾斜、数字滚动。
  - 资源库：左侧「资源库」（或 Ctrl+Shift+L）原生三栏：小应用（.pkt）/ HTML 收藏 / 手机安装包；不再加载旧网页管理页。
  - **坑：窗口四角黑色硬边**。`win.setShape()` 逐行裁圆角会在边缘留下硬黑锯齿，`backdrop-filter` 还会按矩形图层铺一层磨砂。最终方案：主窗口/悬浮窗不再裁形状，`.app` 不做 CSS 圆角，内容铺满矩形，最外层交给 Windows 原生细边框与轻微圆角；悬浮球单独用 `transparent: true` + 圆形 CSS。
  - 悬浮窗（Ctrl+Shift+B）：336×470 玻璃卡，文件模式拖拽直发手机，剪贴板模式读写手机历史；收发双方都显示百分比、进度条和速度。
  - 打包：手动复制 Electron dist 到 `dist/desktop/Pocket-win32-x64`，`electron.exe` 改名 `Pocket.exe`，应用放 `resources/app`；桌面快捷方式「口袋」指向它，图标用新深蓝 `desktop/assets/pocket-icon.ico`。
  - 旧的 `pocket-float.ps1` / `pocket-float.cmd` / `pocket-float-strings.json`、旧「口袋电脑端」快捷方式和旧粉色 LOGO 源文件已删除；`/api/float/start` 只启动 Electron 应用。
- **坑（再次验证）**：PowerShell 5.1 读无 BOM UTF-8 会按 GBK 解析，中文界面文案全部放 JSON，`.ps1` 保持纯 ASCII。

## 2026-11-08（剪贴板 1.4.0）

- **双向多轮剪贴板**：手机 `ClipboardStore`（`files/clipboard.json`，50 条、按文字去重）与电脑 `library/clipboard.json` 同构；两端各加 `/api/clipboard`（GET/POST/DELETE/clear），靠 `time + source` 合并成并集。
  - 手机端走 `PocketBridge.clipboard.*`：`history/add/remove/clear` 同步、`copy/sync` 异步；`sync` 用 UDP 发现的 `platform != android` 设备直连电脑 `/api/clipboard`。
  - 新增内置应用 `clipboard.pkt`（`com.pocket.clipboard` 1.0.0），打开时自动读一次系统剪贴板并记录；Android 10+ 禁止后台读剪贴板，所以不做后台轮询。
- **电脑悬浮窗（历史，已被 Electron 版替代）**：1.4.0 使用 `tools/pocket-float.ps1`（WinForms 自绘）+ `/api/float/start` 由电脑端页面拉起；该实现及配套文件已在电脑端重构中删除。
  - 形态：默认 68×68 悬浮球（渐变光环 + LOGO + 旋转流光 + 在线状态点），点击展开为 368×500 圆角卡片，收起/展开都有缓动动画。
  - 文件模式：拖入文件 → 选中的 Android 设备 → 复用 offer/upload，`HttpWebRequest` 裸流 PUT 并更新进度条。
  - 剪贴板模式：1.2 秒轮询 `Get-Clipboard -Raw`，变化写入本地历史；列表合并手机端历史，可复制到电脑、发到手机、同步、清空。
  - 单实例用命名 Mutex `Local\PocketFloatWindow`；再次点「悬浮窗」不会开出第二个。
  - **坑：WinForms 无边框窗口有系统最小跟踪宽度**（本机 136px），`68×68` 会被撑成 `136×68`。必须重写 `WM_GETMINMAXINFO`，把 `ptMinTrackSize` 设为 1，才能得到真正的圆形小球。
  - **坑：从隐藏窗口的进程 spawn PowerShell 会继承隐藏启动状态**，窗口不显示；`windowsHide` 又会让窗体的首次显示被隐藏。最终方案：Node 通过 `cmd /c start "" /normal powershell ...` 启动（重置显示状态），脚本再用 `GetConsoleWindow + ShowWindow(SW_HIDE)` 隐藏附带控制台。
  - **坑：`detached: true` 在 Windows 上会给子进程 `DETACHED_PROCESS`（无控制台），PowerShell 会直接退出**；改为 `detached: false`，cmd 里的 `start` 本身已经是独立进程。
  - 绘制：Form 开启 `AllPaintingInWmPaint | UserPaint | OptimizedDoubleBuffer`，避免自绘闪烁与半帧；全局 `$ErrorActionPreference = 'Continue'`，单个事件异常不会带走整个悬浮窗。
  - **坑（再次验证）**：PowerShell 5.1 读无 BOM UTF-8 会按 GBK 解析，中文界面文案全部放 `tools/pocket-float-strings.json`，`.ps1` 保持纯 ASCII（只含变量名/英文注释）。
- 版本：1.4.0 / versionCode 19；`dist/pocket-host.json` 同步更新。

## 2026-11-08（深夜）

- **线上问题：手机连电脑热点后两端都搜不到设备**（1.3.0）。
  - 现场：手机 `192.168.137.x`（连的是电脑的 Windows 移动热点，网关 `192.168.137.1`）；手机 8572 端口 TCP 可达，单播 UDP 探测有回复 → 服务和网络都正常，坏在「发现」。
  - 根因：`TransferDiscovery.infoJson()` 少写 `service: "pocket"`，电脑端 `udp.on('message')` 第一句就 `if (json.service !== 'pocket') return`，把手机所有广播都丢了。调试接口 `/api/transfer/debug` 里能看到包已经到了电脑、`lastUdp.sample` 正是手机 JSON，才定位到这一点。
  - 次因：Windows 移动热点下电脑→手机的 `255.255.255.255` / `192.168.137.255` 广播收不到；手机→电脑的广播反而能到。所以不能只靠回包，手机需要主动探测。
  - 修法（1.3.1）：补 `service`；手机每 5 秒向默认网关、本网段广播地址、记住过的设备各发一份「自我介绍 + 探测包」；电脑端也向各网卡定向广播地址发，并记住设备做单播探测。
  - 调试经验：加一个只读的 `/api/transfer/debug`（返回网卡、广播地址、记住的设备、UDP 包计数与最后一条 payload）比抓包快得多。

## 2026-11-08（晚）

- **局域网互传（1.3.0）**：手机同时也是服务端 —— `TransferServer`（8572）+ `TransferDiscovery`（UDP 8571）+ `TransferClient`。
  - 设备发现协议：探测包 `POCKET_DISCOVER/1`，应答/广播 JSON 带 `id/name/platform/host/port/transferPort`；25 秒过期。旧的导入逻辑按 `platform == "android"` 过滤，避免手机出现在「从电脑导入」列表。
  - 传输协议：`POST /api/transfer/offer` 拿 token → `PUT /api/transfer/upload/<token>/<i>` 裸流。手写 HTTP 解析只支持 Content-Length 与 chunked，够用且无第三方依赖；下载支持 Range，方便 `<video>` 拖动。
  - 电脑端页面直接 XHR PUT 到手机（跨源），所以手机服务必须处理 `OPTIONS` 并返回 CORS 头；否则一律 preflight 失败。
  - 坑：Node 端 `req.pipe(ws)` 时不要在 `finish` 之前回响应；用 `replied` 标志防止 `error` 与 `finish` 双发。
  - 坑：手机上传文件名必须走 offer 里的名字，不能直接用 URL 参数，否则中文名会被 URL 编码两次。
- **文件预览**：`PocketWebViewClient` 新增 `/__pocket/files/<id>`，直接流式返回 `files/transfer` 里的文件，`<img>/<video>/fetch` 都能用，不用 base64。
- **内置应用补装**：`ensureBuiltins` 只在首次安装时执行，新增的 `transfer.pkt` / `files.pkt` 通过 `ensureBuiltinIfMissing(asset, id)` 在每次启动时补装。
- **测试环境**：应用宝移除后没有模拟器。用自带 `system-images;android-34;google_apis;x86_64` 手写 `~/.android/avd/pocket_test.avd/config.ini` 建 AVD（`avdmanager` 报 “Package path is not valid” 的 bug），`emulator -no-window` 启动即可。
  - 模拟器里访问电脑用 `10.0.2.2`；adb forward `tcp:18572 tcp:8572` 可从电脑反向测手机服务。
  - 模拟器 UDP 广播不出虚拟网络，测「手机发现电脑」时用 `nc -u 127.0.0.1 8571` 注入一条带 `"host":"10.0.2.2"` 的 JSON。
  - 坑：通过 Git Bash 传中文到 curl 会被终端按 GBK 编码，服务端按 UTF-8 解析就成乱码；中文测试数据要用 Node/Python 直接写 UTF-8 字节，不能看终端输出判断。

## 发布流程（内部备忘）

cp app/build/outputs/apk/release/app-release.apk ../dist/pocket-host.apk
